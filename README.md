##Project name:FitLog

##Short description:FitLog is a modern workout library and planning app that helps users browse exercises, view detailed workout information, and build a personalized workout plan.

##Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Toastify
- Vercel
- FitLog API

 Key Features

1.Navbar,Banner,Footer
- Logo Name 
- My plan page
- 2 badge plan & saved
- Banner browse details

2.Workout Library
Browse a collection of workouts with information such as:
- Workout name
- Muscle groups
- Equipment
- Duration
- Calories burned
- Rating

3.Workout Details
View detailed information for each exercise, including:
- Description
- Equipment
- Difficulty
- Sets and reps
- Duration
- Calories
- Rating
- Step-by-step instructions

4.My Plan
Create a personal workout plan with a maximum of five exercises for the day. Users can:
- Add workouts to today's plan
- Remove workouts
- Mark workouts as completed
- View workout details
- Track total exercises, minutes, and calories
5.Save Workouts
Save exercises for later and access them through the saved section. Saved workouts are stored locally so they remain available after refreshing the page.
